Complaint Management System

About the Project

The Complaint Management System is a console-based C++ project developed using Object-Oriented Programming (OOP). It is designed to manage user complaints efficiently.

Users can submit complaints, view all complaints, search complaints by ID or username, update complaint status, and delete complaints. The system also includes Admin and Staff classes for complaint management.

Features

- Add New Complaint
- View All Complaints
- Search Complaint by ID
- Search Complaint by Username
- Delete Complaint
- Update Complaint Status
- Admin Complaint Management
- Staff Complaint Resolution

OOP Concepts Used

This project demonstrates the following C++ concepts:

- Classes and Objects
- Single Inheritance
- Multilevel Inheritance
- Multiple Inheritance
- Function Overloading
- Encapsulation
- Arrays
- Member Functions

Technologies Used

- Programming Language: C++
- Concepts: Object-Oriented Programming
- Interface: Console-Based Application

Project Classes

1. Complaint: Stores complaint ID, username, complaint details, and status.
2. ComplaintManager: Handles adding, viewing, searching, updating, and deleting complaints.
3. Admin: Manages complaints.
4. Staff: Checks and resolves complaints.

How to Run

1. Download or clone this repository.
2. Open the ".cpp" file in a C++ compiler.
3. Compile and run the program.
4. Select an option from the menu to manage complaints.

Project Purpose

The main purpose of this project is to understand and implement Object-Oriented Programming concepts in C++ through a practical complaint management application.
